## ✨ Возможности

| Команда / Кнопка | Описание |
|------------------|----------|
| `/progress` / 📊 Прогресс | Отправляет изображение `progress.jpg` с текущим процентом готовности игры |
| `/gallery` / 🎨 Галерея | Показывает список категорий концепт-артов; при выборе — отправляет все изображения из соответствующей папки |
| `/backstage` / 🎬 Бэкстейдж | Аналогично галерее, но под каждым фото добавляется описание (название файла, дата, автор) |
| `/info` / ℹ️ О нас | Выводит красивую HTML-визитку студии |

✅ **Главное меню** с кнопками для быстрого доступа ко всем функциям.  
✅ **Inline-клавиатуры** для навигации по категориям.  
✅ **Асинхронная обработка** — высокая скорость работы.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/gamedev-assistant-bot.git
cd gamedev-assistant-bot
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
# Активация:
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id    # можно узнать у @userinfobot
```

### 5. Подготовка медиафайлов
Создайте папку `assets` со следующей структурой (пример):
```
assets/
├── progress.jpg                 # картинка прогресса
├── gallery/
│   ├── персонажи/
│   │   ├── warrior.png
│   │   └── mage.jpg
│   └── окружение/
│       └── forest.webp
└── backstage/
    ├── запись_голоса/
    │   └── studio.jpg
    └── съемки/
        └── behind_scenes.jpg
```

### 6. Запуск бота
```bash
python bot.py
```

Готово! Бот запущен и отвечает на команды. 🎉

## 🕹 Использование

После запуска бот автоматически устанавливает **главное меню** (ReplyKeyboardMarkup) с четырьмя кнопками.  
Также в интерфейсе Telegram доступны **слэш-команды** (настройте через BotFather или добавьте в код).

**Пример диалога:**
1. Пользователь нажимает «🎨 Галерея».
2. Бот присылает список категорий (inline-кнопки).
3. При выборе категории отправляются все изображения из соответствующей папки с подписями.
4. Кнопка «◀️ Назад» возвращает в главное меню.

## 🖼 Добавление своего контента

### 🔹 Прогресс
Замените файл `assets/progress.jpg` на свою картинку.  
Текст под фото редактируется в `handlers/progress.py`.

### 🔹 Галерея
1. В папке `assets/gallery/` создайте **подпапку** с названием категории (например, `персонажи`).
2. Положите туда изображения (`.jpg`, `.png`, `.webp`, `.gif`).
3. Бот автоматически подхватит их при следующем запуске.

### 🔹 Бэкстейдж
Аналогично галерее, но в папке `assets/backstage/`.  
Подпись под фото формируется в `handlers/backstage.py` — вы можете легко изменить шаблон.

### 🔹 Информация о нас
Текст редактируется прямо в `handlers/info.py`.

## ☁️ Деплой (бесплатный хостинг)

Рекомендуемые платформы:

- **[Amvera Cloud](https://amvera.ru/)** — простой, есть бесплатный тариф, подходит для Telegram-ботов.
- **Railway / Render** — удобно, но могут требовать привязку карты.
- **VPS (Ubuntu + systemd)** — полный контроль.

**Краткая инструкция для Amvera:**
1. Загрузите код в Git-репозиторий.
2. Создайте проект в Amvera, укажите репозиторий.
3. Добавьте переменные окружения (`BOT_TOKEN`, `ADMIN_ID`) в настройках.
4. Запустите — бот будет работать 24/7.

Подробный гайд по деплою можно найти в [официальной документации aiogram](https://docs.aiogram.dev/en/dev-3.x/dispatcher/webhook.html).
