# 🎮 LuminTeamBot

**Telegram‑бот для инди‑студии Lumin Core**  
Делитесь прогрессом разработки, концепт‑артами, бэкстейджами и историей команды — прямо в Telegram.

[![aiogram 3.4.1](https://img.shields.io/badge/aiogram-3.4.1-teal.svg?logo=telegram&logoColor=white)](https://docs.aiogram.dev)

## 🎯 Особенности

| Команда / Кнопка          | 🖼 Действие                                                                                  |
|---------------------------|---------------------------------------------------------------------------------------------|
| `/progress` · 📊 Прогресс | Отправляет изображение `progress.jpg` с актуальными процентами готовности игры.              |
| `/gallery` · 🎨 Галерея   | Показывает список категорий концепт‑артов. При выборе — все изображения из выбранной папки. |
| `/backstage` · 🎬 Бэкстейдж | Аналогично галерее, но под каждым фото — расширенное описание (имя файла, дата, автор).   |
| `/info` · ℹ️ О нас        | Выводит красивую HTML‑визитку студии: состав, контакты, ссылки.                            |

✅ **Главное меню** — быстрые Reply‑кнопки под строкой ввода.  
✅ **Inline‑навигация** — удобный выбор категорий без захвата экрана.  
✅ **Асинхронность** — молниеносный отклик даже при большом количестве запросов.

## 🚀 Быстрый старт

### Предварительные требования

- **Python 3.9+**
- **Telegram Bot Token** (получить у [@BotFather](https://t.me/BotFather))

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/lumin-core/LuminTeamBot.git
cd LuminTeamBot

# 2. Создайте виртуальное окружение
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
# .venv\Scripts\activate       # Windows

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env: укажите BOT_TOKEN и ADMIN_ID

# 5. Подготовьте медиафайлы (см. раздел "Добавление контента")
#    Структура папки assets/ должна быть создана вручную

# 6. Запустите бота
python bot.py
```

После запуска бот начнёт отвечать на команды в Telegram.

## 📡 Использование

### Команды бота

После добавления команд через [@BotFather](https://t.me/BotFather) или автоматической установки (см. код `bot.py`) бот реагирует на:

```
/progress   —  текущий прогресс разработки
/gallery    —  галерея концепт‑артов
/backstage  —  закулисье разработки
/info       —  информация о студии
```

### Пример диалога

```text
Пользователь: /gallery
Бот: 🖼 Галерея концепт-артов
     Выберите категорию:
     [ Персонажи ] [ Локации ] [ Предметы ]

Пользователь: [нажимает "Персонажи"]
Бот: [отправляет изображение warrior.jpg]
     *подпись: Персонажи / warrior
     [отправляет изображение mage.png]
     *подпись: Персонажи / mage
```

### Главное меню (Reply‑кнопки)

Бот автоматически отправляет клавиатуру с кнопками:
- 📊 Прогресс
- 🎨 Галерея
- 🎬 Бэкстейдж
- ℹ️ О нас

Нажатие на кнопку равносильно вводу соответствующей команды.

## 🖼 Добавление собственного контента

### 📊 Прогресс
1. Замените файл `assets/progress.jpg` на своё изображение.
2. Отредактируйте текст подписи в `handlers/progress.py`.

### 🎨 Галерея
1. В папке `assets/gallery/` создайте подпапку с названием категории (например, `Персонажи`).
2. Поместите в неё изображения (`.jpg`, `.png`, `.webp`, `.gif`).
3. Бот автоматически подхватит новые категории и файлы при следующем запуске.

### 🎬 Бэкстейдж
1. Аналогично галерее, но в папке `assets/backstage/`.
2. Подпись под фото формируется в `handlers/backstage.py`.  
   Вы можете изменить шаблон, добавить реальные даты, авторов и т.д.

### ℹ️ Информация о нас
Текст визитки редактируется непосредственно в `handlers/info.py`.  
Используйте HTML‑разметку (доступные теги: `<b>`, `<i>`, `<a href="...">`, `<code>` и др.).

## 🛠 Технологический стек

### Основные
- **Python 3.9+** — современный, асинхронный язык.
- **aiogram 3.4.1** — актуальная версия фреймворка для Telegram Bot API.
- **python-dotenv** — безопасное хранение токенов и конфигурации.
- **asyncio** — асинхронная работа без блокировок.

### Поддерживающие
- **Pydantic** (через aiogram) — валидация данных.
- **SQLAlchemy** (не используется, но легко добавляется) — для будущей интеграции с БД.

### Инструменты разработки
- **Black** — форматирование кода.
- **Ruff** — линтинг и сортировка импортов.
- **pre-commit** — автоматические проверки перед коммитом.
